# FINCORE_GRUPO_9_AVANCE_2
Proyecto FinCore - Avance 2 | Programación II | Grupo 9
## Flujo de trabajo

1. Revisar la Issue asignada.
2. Crear una rama desde `main`.
3. Realizar los cambios correspondientes.
4. Hacer commits descriptivos.
5. Abrir un Pull Request hacia `main`.
6. Esperar revisión antes de integrar los cambios.
7. La tarea pasa por Review → QA → Done.

### Importante
No realizar cambios directamente sobre la rama `main`.
